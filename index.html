⚠ The Real Cost of "Cheap" — Capability Gap

The Standard harness excels at deterministic, rule-based agents — FAQ bots, form fills, routing, structured conversations. That's genuinely its strength and best use case.

For complex agentic scenarios, the "true cost" of Standard isn't the credit bill — it's the cost of not having the capability at all: manual workarounds, failed automations, and processes that cannot run.

🚨 Heavy scenarios are in the mix. This class of work — deep reasoning, multi-file generation, broad source aggregation — is architecturally impossible on the Standard harness regardless of budget or development time. There is no workaround.

Methodology Considerations
  • 1Standard harness credits include premium reasoning model costs (10 credits/1K tokens) on top of base feature rates. This reflects the requirement for reasoning capability to attempt complex scenarios. Without reasoning, Standard costs would be lower — but the agent would also be significantly less capable, widening the capability gap.
  • 2On the Standard harness, the same business outcome may require multiple user interactions (each billed separately) if the agent cannot resolve a request in a single pass due to its topic-based routing. The GitHub Copilot harness's agentic loop typically resolves equivalent outcomes in a single task invocation. This model assumes 1:1 interaction parity, which likely understates GHCP's effective cost efficiency.
  • 3As agent complexity increases, Standard development cost grows non-linearly due to combinatorial topic-path explosion. Each new edge case or failure mode requires explicit handling by the development team. The GitHub Copilot harness handles edge cases natively through its reasoning loop, keeping development effort closer to linear.
  • 4GHCP's 45% input-token efficiency advantage compounds at scale — at higher interaction volumes, the orchestration overhead saved per task accumulates into meaningful credit reduction vs. what a comparable Standard build would require for equivalent reasoning depth.
  • 5M365 Copilot USL inclusion covers all Standard harness features for employee-facing (B2E) scenarios at no incremental credit cost. This benefit does not extend to the GitHub Copilot harness — all users consume credits regardless of license. Organizations should weigh this against the capability gap for their specific use case.
